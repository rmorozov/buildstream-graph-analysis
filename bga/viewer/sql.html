Questions worth asking in Perfetto

Load a timeline first (hand it over), then open Query (SQL) and paste one of these. Every bga timeline is a Chrome-trace event stream, so slices are what you query; Plane 1's element spans and Plane 2's process spans are different tracks in the same trace. A finding's Investigate in Perfetto button opens the trace with the matching query from this page attached.

These grow as questions recur. The engine is Perfetto's — this page is a list of questions, not a feature.
