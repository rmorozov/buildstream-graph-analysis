Questions worth asking in Perfetto

Load a timeline first (hand it over), then open Query (SQL) and paste one of these. Every bga timeline is a Chrome-trace event stream, so slices are what you query; Plane 1's element spans and Plane 2's process spans are different tracks in the same trace.

Where did the time actually go, per element?

Plane 1's element spans, aggregated. The answer bga analyze gives you in the Attribution table — here to cross-check it, or to slice it further.

select name, count(*) as spans, sum(dur) / 1e9 as seconds
from slice
group by name
order by seconds desc
limit 25;

Which elements ran the most processes?

Plane 2's lanes. A high count with low total time is a process-storm — many short execs, the shape examples/08-process-storm exists to show.

select t.name as lane, count(*) as processes,
       sum(s.dur) / 1e9 as seconds
from slice s join track t on s.track_id = t.id
where t.name like 'native:%'
group by lane
order by processes desc
limit 25;

What is the sandbox tax here?

Time inside an element's span that no traced process accounts for: staging, checkout, the sandbox itself. Compare with bga correlate's figure.

select p.name as element,
       p.dur / 1e9 as element_seconds,
       (p.dur - coalesce(sum(c.dur), 0)) / 1e9 as unaccounted_seconds
from slice p
left join slice c
  on c.ts >= p.ts and c.ts + c.dur <= p.ts + p.dur and c.id != p.id
group by p.id
order by unaccounted_seconds desc
limit 20;

Where are the longest stalls?

Gaps on the element track: the build was running and nothing was building. The wait-gap analysis in the report, seen directly.

select s.name, s.ts, s.dur,
       lead(s.ts) over (order by s.ts) - (s.ts + s.dur) as gap_after
from slice s
order by gap_after desc
limit 20;

What did one element actually execute?

Replace the name. This is the micro half of the cycle — the commands inside one sandbox, longest first.

select s.name as command, s.dur / 1e6 as ms
from slice s join track t on s.track_id = t.id
where t.name = 'native:core.bst'
order by s.dur desc
limit 40;
