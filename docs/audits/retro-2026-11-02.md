## Proposals

Each is marked `optimization`. The architect shapes them; this report
does not.

1. **A round does not close without its verifiers.** It would compare
   `dev_close_task.py --check`, or the closer's row moves, against
   `agent-runs.md`: each closed row needs a `verifier` run on its
   round. Round 175 closed ten rows on none. A session without the
   agent types should then stop or brief verifiers by hand, not skip
   them silently.
2. **A worktree run's refusal is quoted, then removed at its source.**
   The run ledger's friction cell should carry the refused command and
   the refusing layer. If it is the permission layer, the fix is a
   project allow rule for the plain shell forms the briefs need. The
   other fix is for the briefs to forbid those forms up front. 4 of 6
   runs paid for it this round.
3. **A budget raise shows its own history.** The owner card for a raise
   should print the budget's raises since it was set (eight, +3.0%
   here), not only the step from the current figure. Then a raise reads
   as a trend before it is agreed.
